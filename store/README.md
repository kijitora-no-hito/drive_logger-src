# 公開の手順（ドライブロガー）

## 配布方法

- **GitHub のみ**（`kijitora-no-hito/android-apps` のページ + Releases、タグ `drivelogger-v<版>`）。手順はそちらの `MAINTAINING.md`。
- 更新の確認のため、公開のたびに android-apps の `releases.json` にエントリを足す（`folder` = `drive_logger`、タグ `drivelogger-v<版>`、
  APK 名 `drivelogger-<版>-release.apk`。アプリがこの名前で URL を作る。notes の `- ` の行が［更新内容］に出る）。
- Play の要件に合う形（targetSdk 36・`jp.kjtr.*`・release 鍵・edge-to-edge）にはしてあるが、Play に出すなら更新の確認を flavor で外し、
  ACCESS_BACKGROUND_LOCATION・REQUEST_IGNORE_BATTERY_OPTIMIZATIONS・FGS camera/microphone の申告が要る。

## ビルド

```powershell
cd <このリポジトリのフォルダ>
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat test assembleRelease
Copy-Item app\build\outputs\apk\release\app-release.apk dist\drivelogger-0.8.0-release.apk -Force
# 署名の確認（SHA-256 が下の「鍵の管理」の値）
& "$env:JAVA_HOME\bin\java.exe" -jar "$env:LOCALAPPDATA\Android\Sdk\build-tools\37.0.0\lib\apksigner.jar" verify --print-certs dist\drivelogger-0.8.0-release.apk
# Maps キーが入っているか（何も出なければキー入り。値は表示しない）
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\37.0.0\aapt.exe" dump xmltree dist\drivelogger-0.8.0-release.apk AndroidManifest.xml | Select-String "PLACEHOLDER"
```

## Google Cloud の API キー制限（ユーザー作業・配布の前提）

`local.properties` の `MAPS_API_KEY` は自転車ルートロガー / gps_camera と同じキーをコピーしてある（値はどこにも書かない）。
キーには Android アプリ制限が掛かっているので、次の 2 行を足さないと地図は灰色のまま（線も描かれない。地図以外は動く）。

| パッケージ名 | SHA-1 証明書フィンガープリント | 用途 |
| --- | --- | --- |
| `jp.kjtr.drivelogger` | `43:8B:92:B7:C2:6B:F2:7E:CA:8D:E4:71:98:00:06:DD:DB:F9:EE:36` | release（`release.jks` / alias `drivelogger`） |
| `jp.kjtr.drivelogger` | `E8:23:4F:83:8C:8A:94:8A:D1:82:60:CE:68:6B:F4:AC:DA:64:2F:CF` | debug（`~/.android/debug.keystore`。他アプリと共通） |

API の制限は「Maps SDK for Android のみ」のまま。Google のロゴ・帰属表示は SDK が出す（覆わない）。**Google マップは動画に焼き込まない**（規約。画面だけ）。

## 動画に焼き込む地図（地理院タイル、0.2.0〜）

- 焼き込む地図は国土地理院の地理院タイル（標準・淡色・写真）だけ。国土地理院コンテンツ利用規約により、**出典「出典：国土地理院（地理院タイル）」を表示すれば
  動画への利用も可**なので、地図の窓の下に出典を一緒に焼き込む（外せない）。設定の「このアプリについて」にも出典。
- 既定 OFF。ON のときだけ（録画中と設定の見本）タイルを取得する。送るのはタイルの番号（＝おおよその場所）と通常の通信の情報。プライバシーポリシーに記載済み。
- **取得の作法**（サーバーに負荷をかけない）: User-Agent `DriveLogger/<版> (Android; jp.kjtr.drivelogger)`、同時接続 2、
  表示範囲（回しても欠けない円）＋縁と、動いていれば進む向きに 1 画面分だけ先読み（1 回 40 枚まで・中心のタイルか向きが変わったときだけ計画し直す）、
  ズームは設定の 1 段だけ、取得から 30 日は取り直さない（404 は 0 バイトの印で同じ期間覚える）、失敗は 60 秒あけ、3 回続けて失敗したら 30 秒休む。
  キャッシュは `cacheDir/gsi_tiles`（上限 200 MB・取得の古い順に消す・設定で削除）。
- 公開ページ（android-apps）の説明・プライバシーポリシーにも「地図の焼き込み ON のときだけ国土地理院から取得」「出典」を反映すること。

## 鍵の管理（最重要）

`release.jks` と `keystore.properties` は **git 管理外**。失うと更新版を配れなくなる。**PC とは別の場所に必ずコピーを取ること。**

| 項目 | 値 |
| --- | --- |
| alias | `drivelogger` |
| 形式 | PKCS12、RSA 2048、有効期間 10000 日（2026-10-13 作成。パスワードはランダム・`keystore.properties` にだけある） |
| 証明書 SHA-1 | `43:8B:92:B7:C2:6B:F2:7E:CA:8D:E4:71:98:00:06:DD:DB:F9:EE:36` |
| 証明書 SHA-256 | `22:EE:0F:83:FC:66:1D:9D:AE:96:DB:DA:F8:4C:9B:77:8C:B8:3E:32:DB:DD:6E:78:2F:23:B1:B3:CE:39:7A:F2` |

## 掲載文で触れておくこと

- **ナビ機能はない**。基本は GPS の記録だけ。録画（ドラレコ風）はオプション（開始時の 2 択・走行中に ON/OFF）。
- **権限**: 位置（「使用中のみ」で可）、カメラ（録画するときだけ）、マイク（音声 ON のときだけ。既定 OFF）、通知、フォアグラウンドサービス
  （location / camera / microphone）、WAKE_LOCK、インターネット（地図・更新の確認）。任意: 位置の「常に許可」（落とされたときの GPS 記録の自動再開だけ）、
  電池の最適化から外す確認。Android 9 以下だけストレージの書き込み（ギャラリーへの書き出し・写真の保存）。カメラは録画と写真。写真の選択は Photo Picker（権限なし）。
- **通信先**: Google マップ、地図の焼き込みを ON にしたときの国土地理院（地理院タイル。既定 OFF）、更新の確認の GitHub（OFF にできる）だけ。動画・位置は送らない。
  0.8.0〜 測位の方式で「Google の融合測位」を選んだときは、位置の計算に Google Play 開発者サービスを使う（既定は端末の GPS）。
